# Echo v0.5 Media Request UX 设计

- 日期: 2026-06-08
- 作者: Echo 项目
- 状态: 已确认,直接进入实施计划
- 范围: v0.5 browser auth foundation 合并后的 `/app` 用户媒体请求视觉与可用性切片

## 1. 目标

本切片把 v0.4/v0.5 已可用的用户 media request shell 从裸 HTML 提升为可长期使用的工作台界面。

一句话: **保留现有 templ + htmx + cookie session + CSRF + `/api/me/discovery/*` 行为,只改 `/app` 用户面的结构、样式、响应式和状态呈现。**

包含:

- `/app` shell 引入本地静态 CSS,不走 CDN。
- 顶部栏、搜索区、结果区、请求区、订阅区拥有稳定 class 和布局。
- 搜索结果使用海报卡片,继续消费现有 TMDB poster path。
- 表单输入、select、textarea、按钮和状态文字有一致尺寸、hover、focus 和 disabled 样式。
- 请求和订阅表在移动端通过容器控制溢出,不撑破 viewport。
- 空状态、加载状态和状态 badge 可扫读。
- 测试覆盖关键结构/class、CSS 引入、安全边界和 no-token 回归。

不包含:

- 新业务 API、新后端字段、新 DB migration。
- 媒体详情页、播放页、海报墙重设计。
- 登录页视觉重设计。
- Admin dashboard 全面视觉重做。
- 新前端框架、Tailwind、React、图标依赖或外部字体/CDN。
- 改动 session、Bearer token、CSRF、scope 或 admin-only 路由语义。

## 2. 设计原则

- **操作型界面优先**: Echo `/app` 是重复使用的媒体请求工具,不是营销页。布局应紧凑、可扫读、低装饰。
- **本地资产优先**: CSS 从 `/static/app.css` 提供;真实视觉资产来自 TMDB poster,不新增外链字体或装饰图。
- **稳定尺寸**: poster、表单控件、按钮、表格容器设置稳定尺寸和响应式约束,避免 htmx swap 后布局跳动。
- **安全边界不变**: 前端只改变 HTML/CSS。后端继续通过现有 middleware 和 handler 保证 session、CSRF 与 scope。
- **移动端可用**: 320px viewport 下不出现页面级横向滚动;宽表格只在局部 `.echo-table-scroll` 内滚动。

## 3. 信息架构

`templates.AppShell` 保持三个 lazy-loaded panel,但外层改为工作台布局:

```text
header.echo-topbar
  Echo App / session actions

main.echo-app-shell
  section.echo-panel.echo-panel--search
    /app/discover

  section.echo-panel.echo-panel--requests
    /app/requests

  section.echo-panel.echo-panel--subscriptions
    /app/account
```

各 fragment 继续由现有 htmx endpoint 返回:

- `MediaSearchPanel`: compact toolbar form。
- `MediaSearchResults`: `.media-results-grid` 中的 `.media-result-card`。
- `MediaRequestsTable`: `.echo-table-scroll` 包裹表格,状态用 `.media-status`。
- `MediaSubscriptionsTable`: `.echo-table-scroll` 包裹表格,用户状态、pipeline 状态和 latest state 用 badge。
- `MediaCatalog`: 账号/target 状态表保持在 subscription/account panel 内,同样使用 table scroll。

## 4. 视觉系统

CSS 使用少量语义 class,不引入构建步骤。

色彩:

- Page background: `#f8fafc`
- Surface: `#ffffff`
- Text: `#172033`
- Muted text: `#526071`
- Border: `#dbe3ec`
- Primary: `#2563eb`
- Accent: `#f97316`
- Success: `#15803d`
- Warning: `#b45309`
- Danger: `#b91c1c`

圆角控制在 8px 内。页面 section 不做嵌套卡片;只有搜索结果这种重复 item 使用 card。

## 5. 可访问性与交互

- 所有 input/select/textarea 保留 label。
- Focus ring 使用高对比 outline,不只依赖颜色。
- Hover/focus 不改变元素尺寸。
- `prefers-reduced-motion: reduce` 下禁用 transition。
- Poster 保留宽高和 alt,防止加载跳动。
- 按钮使用明确文字命令;本切片不引入 icon set。

## 6. 测试策略

新增/更新 `internal/web/media_test.go`:

- `/app` shell 必须引入 `/static/app.css`。
- Shell 必须包含 `.echo-topbar`, `.echo-app-shell`, `.echo-panel` 等稳定结构。
- Search fragment 必须渲染 `.media-search-form`。
- Search results 必须渲染 `.media-results-grid`, `.media-result-card`, `.media-result-poster`。
- Requests/subscriptions/catalog fragments 必须使用 `.echo-table-scroll`。
- 现有 no-token、no-admin-fragment 安全断言继续保留。

新增 `internal/web/static/app.css`。不需要 Go 单元测试读取 CSS 全文;结构测试证明模板引用稳定,最终视觉由浏览器/人工检查和后续 screenshot gate 扩展。
