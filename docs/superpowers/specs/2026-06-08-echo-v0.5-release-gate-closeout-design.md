# Echo v0.5 Release Gate Closeout Design

## Context

v0.5 browser auth foundation and the media request UX slice are already on
`main`. Local fake gates, build, migration, templ generation, and web structure
tests passed before merge. The remaining release work is the real-environment
gate closeout called out in `README.md`: confirm the running sidecar, 115 mount,
and release metadata before tagging or declaring the release candidate closed.

The first attempted `integration_real` run did not reach ingest. Echo returned
`sidecar-error` while creating the real 115 account. Direct probing showed that
the running OpenList sidecar on `127.0.0.1:5246` responds at the HTTP layer, but
`/api/admin/storage/list` reports an OpenList envelope error
`code=401,message="token is invalidated"` for the configured gate token. The
environment also originally pointed at `127.0.0.1:5247`, where no process was
listening. This is a gate-environment drift problem, but the current long-path
test surfaces it too late and too generically.

## Goal

Add a real 115 sidecar preflight for the v0.5 release gate so operator mistakes
in `ECHO_TEST_SIDECAR_URL`, `ECHO_TEST_SIDECAR_TOKEN`, or
`ECHO_TEST_115_STORAGE_MOUNT` fail quickly with safe, actionable diagnostics
before Echo starts the long ingest/restore/stream path.

## Non-Goals

- Do not store real tokens, cookies, share URLs, or sidecar passwords in the
  repository.
- Do not change Echo's HTTP API behavior for normal users.
- Do not reset, rotate, or print the running sidecar admin token.
- Do not require Telegram real discovery for the v0.5 release closeout.
- Do not pin `sidecar.default.min_version` until the runtime sidecar reports a
  reproducible build/version string rather than `dev (Commit: unknown)`.

## Design

The release gate gets a small `integration_real` preflight before the existing
`TestReal115ProducerIngestStream` chain. The helper constructs the same
`sidecarclient.Client` that Echo uses, pings the sidecar, reads the public
version, calls `ListStorages`, and checks that `ECHO_TEST_115_STORAGE_MOUNT`
exists in the returned OpenList storage page.

The preflight reports only safe details: sidecar URL, version string, OpenList
envelope code/message, and storage summaries limited to `id`, `driver`,
`mount_path`, and `status`. It never logs the Authorization token, 115 cookies,
share URLs, or secret file contents.

`sidecarclient` gains a tiny exported classifier for OpenList envelope errors.
The underlying `sidecarEnvelopeError` remains the internal carrier used by
`decodeData`; callers that need release-gate diagnostics can extract
`code/message` without depending on an unexported type or string parsing.

## Error Handling

- Missing `ECHO_TEST_SIDECAR_URL` or `ECHO_TEST_115_STORAGE_MOUNT` keeps the
  existing skip behavior.
- Empty `ECHO_TEST_SIDECAR_TOKEN` is allowed to reach the sidecar so the
  preflight can report the real OpenList response, usually a guest/auth error.
- Transport failures fail with a message that points at
  `ECHO_TEST_SIDECAR_URL`.
- OpenList envelope failures fail with `code/message` and a hint to check that
  the token belongs to the same running sidecar instance as the URL.
- Missing storage mount fails with the configured mount and the safe storage
  summaries returned by the sidecar.

## Verification

Local verification must include:

- `go test ./internal/sidecarclient -run TestOpenListEnvelopeErrorDetails -count=1`
- `go test -tags=integration_real ./integration -run TestReal115Preflight -count=1`
  against the real gate environment, expected to fail fast until URL/token/mount
  drift is corrected.
- After the environment is corrected, rerun
  `go test -tags=integration_real -run TestReal115 -timeout 30m -v ./integration/...`.
- Standard release slice checks: `go test ./... -count=1`, `make migrate`,
  `make build`, and `git diff --check`.

## Release Notes

The v0.5 release gate document should record the real preflight outcome with
absolute date, sidecar URL/port, sidecar version string, and whether the 115
long-path gate passed or remains blocked by operator environment drift. Secrets
must be referenced only by environment variable name.
