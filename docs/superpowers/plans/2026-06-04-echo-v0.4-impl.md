# Echo v0.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Echo v0.4 as the user-facing media request and subscription admission layer on top of v0.2 users/auth/quota and v0.3 admin-only discovery.

**Architecture:** v0.4 adds `internal/media` as a facade over TMDB metadata, discovery access policies, request ledger, user subscription projections, and admin approval. Ordinary users only create/search/cancel requests and see redacted status; canonical `discovery_subscriptions`, matches, producer dispatch, and v0.1 ingest remain the existing execution path.

**Tech Stack:** Go 1.22, SQLite, sqlc, chi, templ, htmx, existing `internal/discovery/tmdb`, existing `internal/discovery` scheduler/orchestrator/dispatch, existing v0.2 auth scopes and library grants.

## Non-Negotiable Boundaries

- Do not expose existing `/api/discovery/*` source/profile/candidate/match/run/debug routes to non-admin users.
- Do not expose existing `/ui/discovery/*` admin fragments in the user app.
- Do not let user input set `owner_id`, `library_id`, `producer_profile_id`, `rule_profile_id`, `source_id`, `account_id`, `target_account`, `next_check_at`, `share_code`, `receive_code`, `share_url`, producer args, or job payload.
- User request JSON is strict allowlist only: any key outside `tmdb_id`, `media_type`, `tmdb_language`, `season_filter_json`, `target_id`, and `user_note` returns 400.
- Do not create producer jobs from user request creation. Only v0.3 match accept/dispatch can enqueue `ingest_producer`.
- Do not add 139/189 automatic producer behavior, `by-echo`, WebDAV/S3 output, hash merge, sidecar Go imports, or real upload fallback.

- [ ] **Step 5: Add season helpers**

Create `internal/media/season.go` implementing:

```go
func NormalizeSeasonFilter(raw string) (normalized string, key string, err error)
func UnionSeasonFilters(a string, b string) (string, error)
```

Rules:

- Empty string, JSON `null`, and whitespace mean all seasons: normalized `""`, key `""`.
- Valid explicit filters are JSON arrays of integers from 1 through 99.
- Remove duplicates and sort ascending.
- Reject more than 99 elements and non-array JSON.
