# Echo v0.5 Media Request UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the `/app` media request user shell from bare HTML to a responsive, styled, test-covered templ/htmx workbench.

**Architecture:** Add a local `/static/app.css` stylesheet and stable semantic classes in `internal/web/templates/media.templ`. Keep all existing htmx fragment endpoints, session auth, CSRF, scope checks, and JSON APIs unchanged. Tests assert structure, CSS linkage, and existing security invariants; templ generation updates generated Go output.

**Tech Stack:** Go 1.22, templ v0.2.778, chi/htmx, plain CSS served by the existing `/static/*` file server.

---

## Source Documents

- Accepted design: `docs/superpowers/specs/2026-06-08-echo-v0.5-media-request-ux-design.md`
- Previous auth design: `docs/superpowers/specs/2026-06-07-echo-v0.5-browser-auth-design.md`
- Current user app template: `internal/web/templates/media.templ`
- Current user app tests: `internal/web/media_test.go`
- Current browser glue: `internal/web/static/app.js`

## File Structure

Create:

- `internal/web/static/app.css` - local visual system and responsive `/app` styles.

Modify:

- `internal/web/templates/media.templ` - add stylesheet link and semantic layout/classes for shell, search, results, requests, subscriptions, and catalog.
- `internal/web/templates/media_templ.go` - generated templ output.
- `internal/web/media_test.go` - add UX structure assertions while preserving no-token and no-admin fragment coverage.

## Non-Negotiable Boundaries

- Do not change backend route registration, handler behavior, auth middleware, CSRF logic, or media service APIs.
- Do not add external CSS, fonts, image CDNs beyond the existing TMDB poster URL helper, icon libraries, JavaScript frameworks, or build steps.
- Do not remove existing labels, poster alt text, htmx attributes, or form field names.
- Do not expose `/ui/*`, `/api/discovery/*`, producer profile, rule profile, or raw admin fields in `/app`.

Append this test to `internal/web/media_test.go`:

```go
func TestMediaRequestUXStructure(t *testing.T) {
	fixture := newAppMediaFixture(t, "auto_approve")
	fixture.fake.movies["701"] = tmdb.Media{
		TMDBID:      "701",
		MediaType:   "movie",
		Title:       "Structured Movie",
		ReleaseYear: 2026,
		PosterPath:  "/poster.jpg",
		RawJSON:     `{}`,
	}
	createAppMediaRequest(t, fixture.service, fixture.user.UserID, fixture.target.ID, "701", "movie")

	cases := []struct {
		name string
		path string
		want []string
	}{
		{
			name: "discover shell",
			path: "/app/discover",
			want: []string{
				`class="media-search-form"`,
				`class="media-field"`,
			},
		},
		{
			name: "discover results",
			path: "/app/discover?q=structured&type=movie&language=zh-CN",
			want: []string{
				`class="media-results-grid"`,
				`class="media-result-card"`,
				`class="media-result-poster"`,
				`class="media-request-form"`,
			},
		},
		{
			name: "requests table",
			path: "/app/requests",
			want: []string{
				`class="echo-table-scroll"`,
				`class="media-status media-status--approved"`,
			},
		},
		{
			name: "account tables",
			path: "/app/account",
			want: []string{
				`class="echo-table-scroll"`,
				`class="media-status`,
			},
		},
	}

	for _, tc := range cases {
		t.Run(tc.name, func(t *testing.T) {
			rec := serveAppFragmentAs(t, Deps{Media: fixture.service}, fixture.user, tc.path)
			if rec.Code != http.StatusOK {
				t.Fatalf("%s status=%d body=%s, want 200", tc.path, rec.Code, rec.Body.String())
			}
			body := rec.Body.String()
			for _, want := range tc.want {
				if !strings.Contains(body, want) {
					t.Fatalf("%s missing %q in body=%s", tc.path, want, body)
				}
			}
			assertAppSecurityHeaders(t, rec)
			assertNoAppForbiddenFragments(t, body)
		})
	}
}
```
