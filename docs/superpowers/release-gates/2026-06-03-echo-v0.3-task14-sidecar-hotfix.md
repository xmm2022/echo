## Sidecar Changes

### 1. 115 share-source CAS restore path

Files:

- `/home/nax/.cache/openlist-115cas-src/drivers/115/cas.go`
- `/home/nax/.cache/openlist-115cas-src/drivers/115/cas_test.go`
- `/home/nax/.cache/openlist-115cas-src/drivers/115/meta.go`
- `/home/nax/.cache/openlist-115cas-src/internal/casmeta/casmeta.go`

Behavior recorded:

- For CAS payloads whose source type is `115_share`, restore no longer relies on
  the old share `downurl` path.
- The restore flow receives the shared file into the logged-in 115 account via
  `https://webapi.115.com/share/receive`.
- Restore polls the temporary receive area by SHA1 and size until the file
  appears.
- Range reads use the received account file's pickcode and `DownloadWithUA`.
- The received pickcode is reused across repeated `RangeRead` calls.
- Cleanup deletes the temporary folder and purges recycle when a recycle-bin
  password is configured.
- Missing recycle password is treated as a cleanup error instead of being
  silently ignored.
- Download request failures are sanitized so signed URLs and similar secrets do
  not leak through error strings.

### 2. 115 rapid-upload preflight fix

Files:

- `/home/nax/.cache/openlist-115cas-src/drivers/115/util.go`
- `/home/nax/.cache/openlist-115cas-src/drivers/115/util_test.go`

Behavior recorded:

- `Pan115.rapidUpload` now calls `UploadAvailable()` before computing upload
  signature and token values.
- This hydrates upload metadata and `Userkey` before the upload-init request, so
  source-aware CAS restore no longer fails with `sig invalid`.
- Regression coverage verifies `/app/uploadinfo` is fetched before
  `/4.0/initupload.php`.

## Echo Follow-Up

Real sidecar `/api/fs/link` responses used by the restored file path returned
`header` values as JSON arrays. Echo needed a matching decoder so the `/d`
unsigned fallback could use the returned direct-link headers.

Files committed in this repository:

- `internal/sidecarclient/link.go`
- `internal/sidecarclient/link_test.go`

Behavior recorded:

- Echo now accepts `header` or `headers` values shaped as either `string` or
  `[]string`.
- Stream fallback preserves multi-value direct-link headers when retrying
  through `/api/fs/link`.
