# Echo v0.3 Discovery Release Gate

## Release Blocking Status

This Telegram MTProto + 115 gate is an optional operator gate for the current
release. It is useful when an already-authorized Telegram session file is
available, but it does not block the current tag.

The blocking discovery coverage for this release is:

- local fake full-path discovery integration
- real 115 ingest/stream gate
- standard local verification (`go test`, migration, build, Docker build)
