# Echo v0.5 Media Request UX Gate

Date: 2026-06-08

## Scope

This gate covers the v0.5 media request UX slice that followed the browser auth foundation. It verifies the `/app` user shell now loads local CSS, renders stable responsive structure, keeps TMDB poster result cards bounded, wraps request/subscription/catalog tables for mobile safety, and preserves existing session/auth security boundaries.

## Required Local Gates

- `go test ./internal/web -run 'TestAppShellRendersSessionPanelsAndNoTokenBox|TestAppFragmentsNeverRenderAdminDiscoveryControls|TestMediaRequestUXStructure' -count=1`
- `go run github.com/a-h/templ/cmd/templ@v0.2.778 generate`
- `go test ./internal/web -count=1`
- `go test ./... -count=1`
- `make migrate`
- `make build`
- `git diff --exit-code`

## Verification Notes

The focused web gate proves:

- `/app` shell links `/static/app.css`.
- `/app` shell renders `.echo-topbar`, `.echo-app-shell`, and the three `.echo-panel` sections.
- `/app/discover` renders `.media-search-form` and `.media-field`.
- `/app/discover?q=...` renders `.media-results-grid`, `.media-result-card`, `.media-result-poster`, and `.media-request-form`.
- `/app/requests` and `/app/account` use `.echo-table-scroll` and `.media-status` badges.
- Existing no-token and no-admin-fragment checks still apply.

Manual local smoke check:

- Started `echo serve` with a temporary local config and SQLite DB.
- Verified `GET /static/app.css` returned `200`.
- Verified unauthenticated `GET /app` returned `303` to `/login?next=/app`.
- Bootstrapped a temporary admin password, logged in with a cookie session, and verified authenticated `GET /app` returned `200` with `/static/app.css` and the new shell classes.

## Required Behavior

- `/app` must remain session-authenticated and discovery-scope protected.
- Browser token inputs and localStorage bearer-token glue must not return.
- `/ui/discovery/*` and `/api/discovery/*` must remain absent from user app fragments.
- CSS must be served from the vendored local static path; no external font/CSS/script dependency is introduced.
- Request, subscription, and catalog tables must not create page-level mobile overflow.
