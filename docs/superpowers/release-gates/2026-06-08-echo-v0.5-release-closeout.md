# Echo v0.5 Release Gate Closeout

Date: 2026-06-08

## Scope

This gate closes the v0.5 browser auth foundation and media request UX release
candidate against local build/test gates and the real 115 sidecar environment.
The local gates for both merged v0.5 slices passed before merge; this document
records the remaining real sidecar gate status.

## Real Sidecar Preflight

The release closeout now has a fast `integration_real` sidecar preflight:

```bash
go test -tags=integration_real ./integration -run TestReal115Preflight -count=1
```

The preflight validates:

- `ECHO_TEST_SIDECAR_URL` reaches `/ping`.
- The sidecar version endpoint is readable.
- `ECHO_TEST_SIDECAR_TOKEN` can call `/api/admin/storage/list`.
- `ECHO_TEST_115_STORAGE_MOUNT` exists in the returned OpenList storage page.

Only safe diagnostics are printed: sidecar URL, version string, OpenList
`code/message`, and storage summaries limited to `id`, `driver`, `mount_path`,
and `status`. Tokens, cookies, share URLs, and secret refs are never printed.

## Observed Results

Current `.env.real-gates.local` points `ECHO_TEST_SIDECAR_URL` at
`http://127.0.0.1:5247`, where no sidecar is listening:

```text
real 115 preflight: ping http://127.0.0.1:5247 failed: sidecar unreachable: connect: connection refused
```

The host has an OpenList sidecar listening on `http://127.0.0.1:5246`.
`GET /api/public/settings` reports:

```text
dev (Commit: unknown) - Frontend: rolling - Build at: unknown
```

When the preflight is rerun with `ECHO_TEST_SIDECAR_URL=http://127.0.0.1:5246`,
OpenList rejects the configured gate token:

```text
real 115 preflight: storage list on http://127.0.0.1:5246 failed with OpenList code=401 message="token is invalidated"
```

This means the real 115 long-path gate is currently blocked by operator
environment drift: the configured URL/token/mount must all belong to the same
running sidecar instance before `TestReal115ProducerIngestStream` can validate
ingest, restore, and stream.

   intended running sidecar.
2. Set `ECHO_TEST_SIDECAR_TOKEN` to the token accepted by that same running

3. Confirm `ECHO_TEST_115_STORAGE_MOUNT` names an enabled 115 storage returned
   by `/api/admin/storage/list`.
4. Rerun:

```bash

go test -tags=integration_real -run TestReal115 -timeout 30m -v ./integration/...
```

metadata should wait for the real 115 long-path gate to pass with corrected
operator environment.
