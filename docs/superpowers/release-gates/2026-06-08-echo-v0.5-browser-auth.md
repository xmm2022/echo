# Echo v0.5 Browser Auth Gate

Date: 2026-06-08

Scope: bootstrap admin password, username/password login, web sessions, CSRF for cookie-auth mutations, browser shell token removal, Bearer token compatibility

## Required Local Gates

- `go test ./... -count=1`
- `make migrate`
- `make build`
- `go test ./integration -run TestBrowserAuthFakeFullPath -count=1`

## Required Behavior

- Fresh DB admin cannot log in until `/api/bootstrap/admin-password` succeeds with the bootstrap token.
- Browser login sets an HttpOnly `echo_session` cookie.
- `/api/session/me` returns a redacted user projection and CSRF token.
- Cookie-auth POST without `X-CSRF-Token` returns 403.
- Cookie-auth POST with the current CSRF token succeeds.
- Bearer API token requests continue to work without CSRF.
- `/ui/discovery/*` and `/api/discovery/*` remain admin-only.
- `/app/*` and `/api/me/discovery/*` remain discovery-scope user surfaces.
